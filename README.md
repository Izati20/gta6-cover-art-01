Neon Leonida Cover Studio: a static web app that turns your own photos into multi-panel Leonida cover art. Add one photo or several, click panels to fill them, drag to reframe and scroll to zoom, then shape the poster with five collage layouts (Saga Wall, Lead Duo, Sunset Bands, Six Frame Grid, Main Character), five Leonida colour grades (Vice Sunset, Neon Nights, Teal Dawn, Golden Hour, Midnight Noir), an original stacked-capital title treatment with kicker and subtitle bar, and a painted Leonida scene — ringed sun, glitter sea, causeway, palms — behind any panel left empty. Export a print-textured PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080. Fully offline and private: photos are read on your own machine and never uploaded, and the design is original — no Rockstar logo, artwork or font anywhere.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts # try the studio at http://localhost:8080
```
